### Использование python в работе copilot
- Если для работы copilot'у требуется python, то он есть на моей машине, им можно пользоваться. Путь к python прописан в переменной PATH, поэтому можно просто вызывать команду "py <whatever-you-need>".
- Использование python - не обязательное требование. Если есть инструменты, более подходящие или удобные для решения поставленной задачи, пользуйся ими
- Для python-скриптов нужно создавать отдельную папку python-scripts, чтобы скрипты не смешивались с основным кодом.
- Если в рабочей области есть файл .gitignore, то нужно в него добавить рабочие python-scripts

### Компиляция dotnet проектов
- Если для работы copilot'у необходимо компилировать проекты dotnet, то можно пользоваться компилятором dotnet, установленным и зарегистрированным на моей машине обычным образом.
- Исключение составляют проекты dotnet 9. На моей машине компилятор девятой версии не находится в стандартном месте, и copilot не может его сам найти. Для компиляции проектов dotnet 9 следует использовать компилятор, расположенный здесь: c:\Users\Andrey\.dotnet\dotnet.exe
